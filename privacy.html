プライバシーポリシー

最終更新日：2026年10月1日

対象

clip-uploader（以下「本ツール」）は、運営者が自分のYouTubeチャンネルを管理するための個人用ツールです。運営者以外のユーザーには提供していません。

取得する情報

本ツールはGoogleのOAuth認証を通じて、次の範囲の情報にアクセスします。

  • YouTubeチャンネルの基本情報（チャンネルID・名前）：アップロード先が正しいチャンネルか確認するため
  • 動画のアップロード権限：制作済み動画を投稿するため
  • YouTube Analyticsの集計データ（再生数・視聴時間など）：自分のチャンネルの成績を確認するため

保存と共有

認証情報と取得したデータは、運営者のPC内にのみ保存します。第三者への提供・販売・広告利用は行いません。

Google API サービスの利用

本ツールによるGoogle APIから取得した情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

アクセス権の取り消し

Googleアカウントのサードパーティアクセス設定から、いつでも本ツールのアクセス権を取り消せます。取り消し後、運営者のPCに保存された認証情報は使えなくなります。
